# 새빛대학교 Unity 코어 프로토타입

`SampleScene`을 Play하면 별도의 설정 없이 프로토타입이 자동으로 시작됩니다.

## 현재 구현된 기능

- 16×24 픽셀 캐릭터와 16×16 타일 패턴 캠퍼스
- 잔디, 돌길, 벽돌, 지붕, 창문, 나무와 실내 가구의 구분 가능한 픽셀 무늬
- WASD·방향키 캐릭터 이동
- 캠퍼스 건물 충돌과 총장실 출입
- 울산대학교 구조를 간소화한 대형 캠퍼스와 순환도로
- 남쪽 정문, 중앙 운동장, 서쪽 학술 구역, 동쪽 학생생활 구역, 북쪽 기숙사, 남동쪽 체육 구역
- E·Space로 학생, 교수, 교직원과 대화
- 수업·점심·근무·상담·동아리·퇴근 시간이 다른 개인별 NPC 일과표
- 캐릭터별 하루 1회 대화와 5칸 하트 관계 표시
- 대화 중 알림 없이 별도 관계 수첩에서만 하트 확인
- 총장 인벤토리와 취향별 선물 효과
- 선물 반응 테스트를 위한 아이템별 20개 지급
- 선물을 받은 캐릭터의 성격별 고유 반응 대사
- 하루 종료 자동 저장과 다음 실행 시 불러오기
- 행동에 따라 언변·재정·협상 능력 경험 상승
- 하루 정산에서 스킬 포인트 상승 알림
- Tab으로 결재함 열기
- 강제 팝업 없이 느낌표가 표시되는 결재 서류 아이콘
- 임금 인상안 승인·수정·보류
- 1년에 평균 2~3회 발생하는 희귀 돌발 사건
- 오후 8시 하루 종료 정산
- 다음 날 진행

## 테스트 순서

1. 캠퍼스를 이동해 NPC에게 말을 겁니다.
2. 총장실 문 앞에서 E를 눌러 실내에 들어갔다가 다시 나옵니다.
3. I 키로 인벤토리를 확인하고 대화창에서 선물을 줍니다.
4. R 키 또는 관계 아이콘을 눌러 인물별 하트를 확인합니다.
5. Tab을 눌러 결재안을 선택합니다.
6. 오후 8시까지 기다리거나 이동하며 하루 정산을 확인합니다.
7. 대화·결재·협상 행동에 따라 해당 능력이 성장하며 밤에 결과가 표시됩니다.

현재 그래픽은 시스템 검증용 임시 도트입니다. 다음 단계에서 실제 타일맵, 애니메이션, 모바일 터치 조작과 저장 시스템으로 교체합니다.

## 총장실 콘셉트

`ConceptArt/president-office-concept-v1.png`을 실내 도트 제작 기준으로 사용하며, 같은 이미지를 Unity 총장실 배경에 실제 적용했습니다. 책상·결재 구역, 방문객 응접 공간, 책장과 전시 구역, 남쪽 출입구와 넓은 이동 통로로 구성합니다.
