# Campus in Bloom

Campus in Bloom은 대학 총장이 되어 10년 동안 캠퍼스를 운영하고, 학생·교수·교직원과 관계를 쌓아가는 따뜻한 2D 픽셀아트 생활 시뮬레이션 게임입니다.

## 개발 환경

- Unity 6
- C#
- PC, 모바일 웹 플랫폼 목표

## 현재 프로토타입

- 캠퍼스 탐색과 건물 충돌
- 시간대별 NPC 일과와 대화
- 호감도, 선물, 인벤토리
- 교내 편의점과 개인 소지금
- 결재와 돌발 사건
- 행동 기반 능력 성장
- 하루 결산과 저장
- 캠퍼스 지도
- 교체 가능한 캐릭터·초상화·월드 이미지 구조

게임의 세부 기획은 [GAME_DESIGN_DOCUMENT.md](GAME_DESIGN_DOCUMENT.md), 이미지 교체 규칙은 [ART_REPLACEMENT_GUIDE.md](Assets/SaebitPrototype/ART_REPLACEMENT_GUIDE.md)에서 확인할 수 있습니다.
